## 2. 문제의 원인

### 2-1. 그래픽 완성도
- 던전이 **평평한 바닥 + 네 벽 + 상자 몇 개**라 공간감이 없다. 장식(풀·바위·나무)은 있지만 지형 높낮이·건축물·조명 장치가 없다.
- 장애물이 색만 다른 **단색 박스**(상자·기둥·수정)다.
- 보스 3종이 아직 코드 도형(임시 모델)이라 몬스터와 스타일이 다르다.
- 전투 효과는 부채꼴·파편·번쩍임·피해 숫자까지는 있으나 궤적(트레일)·레벨 업·희귀 아이템 발광·보스 등장 연출이 약하다.

### 2-2. 스테이지가 짧은 이유
- 한 던전 = 열린 경기장 하나. 적 11마리가 흩어져 있어 **3~4분**이면 전멸 → 보스 → 끝.
- 길·방·분기·이벤트가 없어 "탐험"이 없다. 상자 3개는 처음부터 보인다.

### 2-3. 모바일 UI
- 가로 모드에서 위쪽 정보 패널(좌·우)과 우측 상단 메뉴·장비 버튼, 하단 조작 버튼이 **고정 px** 로 배치돼 좁은 화면(높이 390)에서 서로 가깝다.
- 글자 12~13px 구간이 있고 Safe Area(노치·홈 인디케이터)는 하단 버튼에만 반영된다.
- 메뉴 패널은 v1.7.0 에서 스크롤 가능하게 고쳤다.

### 2-4. 공격 타이밍 (사용자 지적)
- 피해 판정은 버튼을 누른 순간 들어가지만, 검 **동작은 30%(약 0.1초) 뒤로 당겼다가** 휘두르기 시작해 "늦게 나간다"고 느껴진다. 동작의 뒤로 당김을 12% 로 줄이고 바로 휘두르게 한다.
