# HERO X 게임 가이드

## 현재 버전에서 할 수 있는 것 (v0.1.0, 1단계)

- 3D 공간(풀밭 바닥, 나무 상자, 돌기둥, 담장, 바위)에서 캐릭터를 움직입니다.
- 카메라가 캐릭터 위 뒤쪽에서 부드럽게 따라옵니다.
- 상자·기둥·담장은 통과할 수 없고, 영역 바깥 벽 너머로 나갈 수 없습니다.
- 캐릭터는 이동 방향으로 몸을 돌리고, 걸을 때 팔다리를 흔듭니다.

아직 없는 것: 적, 공격, 체력, 아이템, 보스, 저장, 설정 화면. (2단계부터 순서대로 추가됩니다. `CLAUDE.md` 9장 참고)

## 조작법

| 키 | 동작 |
| --- | --- |
| `W` 또는 `↑` | 앞으로 (화면 위쪽) |
| `S` 또는 `↓` | 뒤로 (화면 아래쪽) |
| `A` 또는 `←` | 왼쪽 |
| `D` 또는 `→` | 오른쪽 |
| `H` | 조작 안내 열기/닫기 |

- 두 키를 같이 누르면 대각선으로 움직입니다. (대각선이라고 더 빨라지지 않습니다)
- 한/영 전환 상태와 상관없이 키 위치로 동작합니다.
- 키를 바꾸려면 `src/game/GameConfig.ts` 의 `controls` 를 수정합니다.

## 화면 구성

- **조작 안내 화면**: 게임을 켜면 먼저 보입니다. `시작하기` 또는 `H` 로 닫습니다.
- **왼쪽 아래 상태 표시**: `H: 조작 안내 · FPS 60` 처럼 초당 프레임 수를 보여줍니다. FPS 표시는 `GameConfig.debug.showFps` 로 끌 수 있습니다.
- **오류 상자**: 실행 중 문제가 생기면 화면 위쪽에 빨간 상자로 원인을 보여줍니다.

## 바꿀 수 있는 설정 (`src/game/GameConfig.ts`)

| 항목 | 기본값 | 허용 범위 | 설명 |
| --- | --- | --- | --- |
| `player.moveSpeed` | 7 | 1 ~ 30 | 이동 속도 |
| `player.turnSpeed` | 14 | 1 ~ 40 | 몸을 돌리는 속도 |
| `player.radius` | 0.5 | 0.2 ~ 2 | 충돌 반지름 |
| `player.colors` | 파랑/노랑 | 색상 코드 | 임시 캐릭터 색 |
| `camera.offset` | (0, 13, 11) | y 3~40, z 0~40 | 카메라 위치 (높이, 뒤쪽 거리) |
| `camera.smoothing` | 6 | 0.5 ~ 30 | 카메라가 따라붙는 속도 |
| `camera.fov` | 50 | 30 ~ 90 | 화각 |
| `world.arenaHalfSize` | 28 | 10 ~ 200 | 이동 가능 영역 크기 |
| `world.obstacles` | 10개 | 자유 | 장애물 목록 (x, z, w, d, h, color) |
| `graphics.shadows` | true | 켜기/끄기 | 그림자 (느린 PC 에서는 끄면 부드러워짐) |
| `debug.showFps` | true | 켜기/끄기 | FPS 표시 |

범위를 벗어난 값은 게임 시작 시 자동으로 보정됩니다.

## 캐릭터 모델 교체 (예정)

- 현재 캐릭터는 단순 도형으로 만든 임시 모델(`src/player/models/PlaceholderModel.ts`)입니다.
- 전용 3D 모델(.glb)을 넣을 때는 같은 `PlayerModel` 인터페이스를 구현하는 파일을 추가하고 `Player.setModel()` 로 교체합니다. 모델의 정면은 +Z 방향이어야 합니다.
- 에셋 파일 위치와 적용 방법은 모델 기능이 추가될 때 이 문서에 기록합니다.
